# /scenario

対象: $ARGUMENTS

## 手順
1. 基準になる事実を集める（並列）：
   - `web-researcher`：過去の実績、統計、似た事例（出典つき）。天気なら気象庁などの予報と信頼度、市場なら公式の統計
   - 会話やファイルにある、ユーザー自身の過去の実績（以前の集客数、似た作業にかかった時間など）
2. `uncertainty-analyst` に、集めた材料と対象を渡して分析させる。
3. `red-team-reviewer` に分析結果を渡し、楽観に偏っていないか、見落としている要素がないかを確認させる。数字が多ければ `numbers-verifier` も使う。
4. 次の形で報告する：
   - **結論**（基本の見立てと幅を1〜2行で）
   - **シナリオ表**：要素 / 基本 / 幅（楽観〜悲観）/ 根拠 / 見るべき兆し / 備え / 確度
   - **今決めること・いつまでに決めること**（判断の期限、やめる・延期する基準）
   - **分からないまま残ること**

## 注意
- 1点の数字ではなく幅で示す。見せかけの細かい数字を出さない。
- 価格・株価はシナリオとして示し、投資の助言はしない。
