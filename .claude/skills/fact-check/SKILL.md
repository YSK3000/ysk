# /fact-check

対象: $ARGUMENTS
（空なら、この会話で直前に出した回答を対象にする）

## 手順
1. 対象を確定する（ファイルなら読み込む、URLなら取得する）。
2. `fact-checker` サブエージェントに、対象の全文を渡して検証させる。
3. 数字・割合・倍率・日付計算・表が含まれていれば、`numbers-verifier` を**同時に**起動して検算させる。
4. 推測や結論が中心の文章なら、`red-team-reviewer` も同時に使い、見落としや反対の証拠を洗い出す。
5. 結果を統合して、次の形で報告する：
   - **判定表**（主張 / 判定 / 正しい内容 / 根拠URL・日付 / 確度）
   - **直す必要がある箇所**と修正案
   - **確認できなかったこと**
   - **総合判定**：このまま使ってよい / 直してから使う
6. 対象が自分の回答だった場合は、修正した回答もあわせて示す。
