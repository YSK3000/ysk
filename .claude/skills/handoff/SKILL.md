# /handoff

保存先: $ARGUMENTS

## 手順
1. この会話から、次の情報を集める：作っているもの・最新の版・終わったこと・残っていること・ユーザーと決めたこと（理由つき）・守るルール（ユーザーとの約束ごと）・未解決の質問・関係するファイルの場所。
2. `docs-writer` サブエージェントに渡し、引き継ぎメモのひな形どおりに書かせる。
3. 書けたら自分で読み直し、次を確認する：
   - 秘密情報（鍵・トークン・パスワード・共有リンク・ファイルID・個人情報）が入っていない
   - 推測が事実として書かれていない
   - 「次の一歩」が1行で具体的
4. 保存先が空なら、スクラッチパッドに `handoff-<日付>.md` として保存する。**公開リポジトリにはコミットしない**（ユーザーが明示的に頼んだ場合を除く）。
5. ユーザーにファイルを渡し（SendUserFile が使えればそれで）、新しいセッションでは最初にこのメモを読ませるよう伝える。
